# pk_pd_section_criteria.md

Section purpose:
Accurately summarize pharmacokinetic and/or pharmacodynamic findings without unsupported mechanistic or clinical inference.

Section-specific success criteria:
- correctly characterizes key PK/PD parameters and trends
- does not overstate descriptive findings
- avoids unsupported mechanistic explanations
- distinguishes observed results from stronger interpretive claims
- maintains scientific restraint

Additional dimensions to consider:
- parameter_interpretation_accuracy
- trend_characterization
- exposure_response_restraint
- mechanistic_inference_control

Section-specific critical failure triggers:
- incorrect PK parameter interpretation
- incorrect trend description
- unsupported exposure-response claim
- unsupported biological or clinical inference
- failure to distinguish descriptive findings from stronger claims

Weighting adjustment guidance:
Increase weight on:
- source faithfulness
- section purpose fit
- unsupported-content control

Practical note:
PK/PD outputs often fail through subtle overinterpretation rather than obvious fabrication.
