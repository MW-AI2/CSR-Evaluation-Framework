# tlf_summary_section_criteria.md

## Section Purpose
Summarize the relevant table/listing/figure content accurately, clearly, and without over-interpretation.

## Section-Specific Success Criteria
- accurately reflects the table or figure content
- correctly handles treatment groups and analysis populations
- preserves denominator awareness
- avoids unsupported directional or comparative claims
- provides clear but restrained interpretation

## Additional Dimensions to Consider
- table fidelity
- denominator and population correctness
- numerical interpretation accuracy
- overinterpretation control

## Section-Specific Critical Failure Triggers
- incorrect numerical summary
- incorrect denominator or analysis population interpretation
- unsupported treatment comparison
- misleading directional claim
- omission of a key table finding that changes interpretation

## Weighting Adjustment Guidance
Increase emphasis on:
- source faithfulness
- internal consistency
- section purpose fit

## Practical Note
This section type requires high numerical and population-definition discipline.
